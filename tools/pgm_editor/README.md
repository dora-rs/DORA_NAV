# PGM栅格地图编辑器

离线编辑PGM栅格地图的工具，用于去除SLAM建图过程中的人影残留等干扰点。

## 功能特性

- **多种编辑模式**
  - 画笔模式（B键）：清除障碍物，将像素设置为空闲区域
  - 橡皮擦模式（E键）：添加障碍物，将像素设置为占用区域
  - 矩形填充模式（R键）：快速填充大面积区域

- **便捷操作**
  - 可调节画笔大小（+/-键）
  - 支持撤销/重做（Z/Y键）
  - 缩放和平移视图（鼠标滚轮和右键拖动）
  - 实时预览编辑效果

- **灵活保存**
  - 支持另存为新文件
  - 或覆盖原文件

## 编译方法

```bash
cd tools/pgm_editor
mkdir build && cd build
cmake ..
make
```

## 使用方法

### 基本用法

```bash
# 编辑地图（覆盖原文件）
./pgm_editor map.pgm

# 编辑地图（另存为新文件）
./pgm_editor map.pgm map_edited.pgm
```

### 操作说明

#### 鼠标操作
- **左键拖动** - 在当前模式下绘制/擦除
- **右键拖动** - 平移视图
- **滚轮** - 缩放视图

#### 键盘快捷键
- **B** - 切换到画笔模式（清除障碍物）
- **E** - 切换到橡皮擦模式（添加障碍物）
- **R** - 切换到矩形填充模式
- **+/=** - 增加画笔大小
- **-/_** - 减小画笔大小
- **Z** - 撤销上一步操作
- **Y** - 重做操作
- **S** - 保存地图（运行时保存）
- **H** - 显示帮助信息
- **ESC/Q** - 退出编辑器

## 使用场景

### 去除人影残留

1. 启动编辑器加载建图后的PGM文件
2. 按 **B** 键切换到画笔模式
3. 用鼠标左键拖动清除人影区域（将黑色障碍物区域变为白色空闲区域）
4. 使用 **+/-** 键调整画笔大小以适应不同区域
5. 使用 **Z** 键撤销错误操作
6. 完成后退出，选择保存修改

### 添加虚拟障碍物

1. 按 **E** 键切换到橡皮擦模式
2. 用鼠标左键拖动添加障碍物区域
3. 或按 **R** 键使用矩形填充模式快速添加大面积障碍物

## 技术说明

- 基于OpenCV实现
- 支持标准PGM格式（P2/P5）
- 灰度值范围：0-255
  - 0 = 占用（黑色，障碍物）
  - 128 = 空闲（灰色，可通行区域）
  - 与map_trans工具的颜色定义保持一致
- 最多支持50步撤销/重做操作

## 注意事项

1. 编辑前建议备份原始地图文件
2. 编辑时注意不要误删除真实的墙壁等障碍物
3. 保存时会覆盖目标文件，请谨慎操作
4. 如果同时有YAML元数据文件，编辑后不会自动更新YAML文件中的时间戳等信息

## 与map_trans工具配合使用

```bash
# 1. 使用map_trans将PCD点云转换为PGM地图
cd tools/map_trans/build
./pcd2pgm ../config/config.json

# 2. 使用pgm_editor编辑生成的地图
cd ../../pgm_editor/build
./pgm_editor ../../map_trans/data/output/map.pgm

# 3. 编辑完成后保存，即可用于导航
```
